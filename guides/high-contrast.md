# High Contrast palette

One set of 16 terminal colours, a dark half and a light half, shared by every terminal in this
repository. Each terminal that can follow the system appearance switches between the two halves on
its own, so the same command looks the same in every app on every platform.

## How the colours were chosen

- **Dark mode** uses vivid, saturated colours on pure black. Saturated colours are easier to tell
  apart at a glance than pale ones, which matters more than squeezing out the last point of
  contrast. White is a neutral white, not a tinted one.
- **Light mode** takes the same hues and darkens each one only as far as it needs to reach 7:1
  (WCAG AAA) on white, keeping it as saturated as possible. Yellow leans towards amber, since a
  dark pure yellow reads as olive. The bright row is a step darker again.
- **Bold text keeps its colour.** Bold does not switch to the bright row, which is the softer row
  in dark mode.

> [!IMPORTANT]
> [`palette/high-contrast.json`](../palette/high-contrast.json) is the only place a colour is
> defined. Every theme file is written from it by
> [`scripts/build-themes.py`](../scripts/build-themes.py), including the table below. Edit the
> palette, run `python3 scripts/build-themes.py`, commit both. CI fails when a generated file is
> out of date or a colour drops below its contrast floor.

## The colours

Contrast is measured against each mode's background. Light mode holds every text colour to 7:1.
Dark mode holds them to 4.5:1 (WCAG AA) and most sit far above 7:1; its two blacks are background
and hint shades, so they are exempt.

## Where each terminal gets it

| Terminal | Files | Follows light and dark |
| --- | --- | --- |
| Terminal.app | [`mac/terminal-app/`](../mac/terminal-app/) | Yes, through a small login agent that switches between the High Contrast Dark and Light profiles |
| iTerm2 | [`mac/iterm2/high-contrast.json`](../mac/iterm2/high-contrast.json) | Yes, one Dynamic Profile with separate light and dark colours |
| Kitty 0.38+ | `<platform>/kitty/*-theme.auto.conf` | Yes, read automatically from the Kitty config folder |
| Alacritty | `<platform>/alacritty/high-contrast-*.toml` | No: imports the dark half, swap the import for light |
| Hyper | `<platform>/hyper/hyper.js` | No: carries the dark half |
| Windows Terminal | [`windows/windows-terminal/high-contrast.json`](../windows/windows-terminal/high-contrast.json) | Yes, through a light and dark colour scheme pair |
| Ptyxis (Ubuntu 25.10+) | [`linux/ptyxis/high-contrast.palette`](../linux/ptyxis/high-contrast.palette) | Yes, one palette with both halves |
| GNOME Terminal (Ubuntu 24.04) | [`linux/gnome-terminal/`](../linux/gnome-terminal/) | No: carries the dark half |

[vscode-config](https://github.com/zaccesss/vscode-config) and
[jetbrains-config](https://github.com/zaccesss/jetbrains-config) carry the same colours for the
integrated terminals in VS Code and the JetBrains IDEs.

> [!NOTE]
> Terminal.app has no light and dark pair of its own. `mac/install.sh` builds
> [`terminal-appearance.swift`](../mac/terminal-app/terminal-appearance.swift) into
> `~/.local/bin` and runs it as a login agent. It switches every tab already on a High Contrast
> profile, plus the default for new windows, whenever macOS changes appearance; a tab put on any
> other profile is left alone. macOS asks once for permission to let it control Terminal.

Setup for each terminal is in [setup.md](setup.md).
